# Internal Security Audit

## Project Overview

This project documents a simulated internal security audit conducted as part of my cybersecurity training. The audit evaluates the security posture of the fictional organization Botium Toys by examining existing security controls, identifying security gaps, assessing organizational risk, and evaluating compliance considerations.

The assessment identified significant weaknesses involving access control, data protection, business continuity, authentication, and threat detection.

**Overall Risk Level: High**

---

## Objectives

- Identify organizational assets and potential security risks
- Evaluate existing security controls
- Identify vulnerabilities and security gaps
- Assess compliance considerations
- Prioritize identified risks
- Recommend appropriate remediation measures

---

## Audit Methodology

1. Reviewed the organization's audit scope, goals, and risk assessment
2. Evaluated existing administrative, technical, and physical security controls
3. Identified potential threats, vulnerabilities, and security gaps
4. Assessed controls against relevant compliance considerations
5. Evaluated the potential impact of identified weaknesses
6. Prioritized risks based on their potential impact
7. Developed remediation recommendations

---

## Key Findings

The audit identified several significant security gaps:

- Least privilege is not adequately implemented
- Separation of duties requires improvement
- Sensitive information is not adequately encrypted
- Critical data is not adequately backed up
- A formal disaster recovery plan has not been established
- Password security requires improvement
- A centralized password management solution is not implemented
- An intrusion detection system (IDS) is not currently deployed
- Legacy systems require more consistent maintenance

Existing security strengths include firewall protection, antivirus software, physical locks, CCTV surveillance, and fire detection and prevention controls.

---

## Priority Recommendations

The highest-priority remediation actions include:

1. Implement least privilege and role-based access control (RBAC)
2. Encrypt sensitive information at rest and in transit
3. Establish regular backups and a formal disaster recovery plan
4. Strengthen password and authentication controls
5. Deploy intrusion detection capabilities
6. Establish a documented maintenance and patching schedule for legacy systems
